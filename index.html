AuraNow

AI-Powered YouTube Comment Analytics Platform

Production-grade microservice analytics platform that processes YouTube video comments using a full NLP/ML pipeline. Separate FastAPI API + async worker with Redis queuing, MongoDB persistence, JWT authentication, Dockerized multi-container deploy on Azure, and a React dashboard for real-time insight delivery.

ML Pipeline (7-Step)
1
Fetch YouTube comments via YouTube Data API + URL validation
2
Preprocess text + generate sentence embeddings
3
Reduce dimensions with UMAP
4
Cluster with HDBSCAN → compute cluster medoids
5
Build RAPTOR-style hierarchical summary tree
6
Persist run metadata + RAPTOR nodes in MongoDB
7
Enable AI chat Q&A over analytics via RAG

System Architecture

🔁 Request & Processing Flow
01
User submits YouTube URL (any format)
Standard, short, embed, mobile — all supported
02
FastAPI validates + extracts 11-char video_id
Regex validation + duplicate detection per user_id
03
Job pushed to Redis queue
Async worker container picks it up independently
04
Worker runs full NLP pipeline
Embeddings → UMAP → HDBSCAN → RAPTOR tree
05
Results persisted to MongoDB
Versioned run folders + RAPTOR nodes for RAG chat
06
Frontend polls status endpoint
Live status: pending → processing → completed
